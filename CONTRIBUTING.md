# Как помочь проекту

<p><b>Русский</b> · <a href="#in-english">English</a></p>

Спасибо, что заглянули! Самая ценная помощь — найденные ошибки и проверка колоды на разных устройствах.

## Нашли ошибку в тексте или переводе

Откройте [форму «Ошибка в тексте или переводе»](../../issues/new?template=translation-error.yml). Номер серии виден на обороте карточки, если раскрыть «перевод фрагмента»: «Серия 3 · 10/17».

- **Не пишите спойлеры в заголовке** — его видят все, кто открывает список задач.
- Одна ошибка — одна задача. Если ошибок много в одной серии, можно собрать их в одну.

## Колода не импортируется или выглядит не так

Откройте [форму «Проблема с установкой или видом»](../../issues/new?template=install-problem.yml) и приложите скриншот. Напишите приложение и устройство: Anki на компьютере, AnkiDroid, AnkiMobile или AnkiWeb.

## Почему правки принимаются через задачи, а не pull request

Файл колоды `.apkg` собирается из исходников, которых нет в этом репозитории. Поэтому исправления из задач переносятся в исходники и выходят в следующем [релизе](../../releases). Pull request подходит для README, файлов в `docs/` и книги `book/`.

## In English

Thank you for stopping by! The most useful help is reporting mistakes and checking the deck on different devices.

- **Mistake in a text or translation:** use the [text or translation error form](../../issues/new?template=translation-error.yml). The episode number is on the back of the card when you open the fragment translation: "Серия 3 · 10/17" (Episode 3 · 10/17). Please keep spoilers out of the issue title.
- **The deck does not import or looks wrong:** use the [install or display problem form](../../issues/new?template=install-problem.yml) and attach a screenshot.
- **Why issues, not pull requests:** the `.apkg` file is built from sources that are not in this repository, so fixes go into the sources and ship in the next [release](../../releases). Pull requests are welcome for the README, `docs/` and the book in `book/`.
