# Настройка под себя

[English](./customize.en.md)

Правки стиля делаются в Anki на компьютере: **Инструменты → Управление типами записей** (Tools → Manage Note Types) → «Wordkeep (Oxford 3000)» → **Карточки…** (Cards…) → **Таблица стилей** (Styling). Правило вставляется в самый конец и подхватывается на всех устройствах после синхронизации.

Все рецепты ниже проверены на настоящих карточках колоды: обычной и последней карточке сцены, в дневной и ночной теме.

В версии 2.0 на лицевой стороне по умолчанию только слово, а фрагмент истории свёрнут на обороте в «контекст». Рецепт «только слово на лицевой стороне» больше не нужен.

## Фрагмент снова на лицевой стороне

Как было в версиях 1.x: слово и фрагмент истории на лицевой стороне.

```css
.front .example { display: block !important; margin-top: 28px; }
```

На лицевой стороне появится ярлык документа и фрагмент этой карточки — без рисунка, без картины места и без сцены истории. На последней карточке сцены ярлык будет мельче, как внутри сцены. Сама сцена по-прежнему ждёт на обороте.

## «контекст» сразу раскрыт

Стилями это не сделать: свёрнутый `<details>` раскрывается только атрибутом в шаблоне. Поэтому придётся поправить сам шаблон:

1. **Инструменты → Управление типами записей** → «Wordkeep (Oxford 3000)» → **Карточки…**
2. Открой **Шаблон оборота** (Back Template).
3. Найди `<details class="ctx">` и замени на `<details class="ctx" open>`.

Так же можно сразу раскрыть «перевод»: `<details class="ru-hint" open>`. На последней карточке сцены «контекста» нет — там этот фрагмент уже стоит в сцене.

Учти: после правки шаблона обновления колоды больше не будут менять его сами. Когда выйдет новая версия с другим шаблоном, перенеси его вручную — см. [«Если шаблон не обновился»](#если-шаблон-не-обновился).

## Без «Ранее» и «Кто здесь»

```css
.sc-prev { display: none !important; }   /* строка «Ранее» над сценой */
.sc-who { display: none !important; }    /* список «Кто здесь» под сценой */
```

Можно оставить любую одну строку. Сама сцена останется.

## Без рисунков и картин мест

```css
.wpic, .back .art-panel { display: none !important; }
.back .word, .back .ru { margin-right: 0 !important; min-height: 0 !important; }
```

Вторая строка убирает отступ, который оставлен под рисунок. Сцена истории, «контекст» и «перевод» останутся.

## Сколько новых карточек в день

Шестерёнка у колоды → **Параметры** (Options) → **Ежедневный лимит** (Daily Limits) → **Новых карточек в день** (New cards/day). По умолчанию 15, новые карточки идут после повторений. Подойдёт любое число: сцена приходит, когда пройдены все её слова. Если день кончился посреди сцены, она придёт на следующий день, после оставшихся слов этой сцены. Хочешь читать больше — подними лимит на сегодня.

Перемешивать новые карточки нельзя. Их порядок — это порядок сюжета.

## Если шаблон не обновился

Если ты когда-то правил шаблон карточки, обновление его не трогает. Узнать легко: после перехода на 2.0 на лицевой стороне по-прежнему виден фрагмент истории, а сцен на обороте нет. Колода при этом работает как раньше, просто без сцен.

Чтобы получить новый вид, перенеси шаблон вручную:

1. **Инструменты → Управление типами записей** → «Wordkeep (Oxford 3000)» → **Карточки…**
2. В **Шаблон лица** (Front Template) вставь целиком [`template/front.html`](./template/front.html).
3. В **Шаблон оборота** (Back Template) — [`template/back.html`](./template/back.html).
4. Сохрани и проверь карточку. Свои правки, если они нужны, внеси заново.

## Что не настраивается

- **Перевод только русский.**
- **Шрифты грузятся из Google Fonts.** Без интернета Anki возьмёт запасные (Georgia, PT Serif, Consolas). Карточки работают, но выглядят проще.
